# yotathai.boq — จากโมเดล 3D ไปถึงรายการ BOQ

ขั้นที่ 1: อ่านปริมาณจากไฟล์ IFC (Qto_*) รวมต่อชนิดวัตถุ แล้วเสนอ "รายการที่เป็นไปได้" ใน boq-catalog
(หลักเกณฑ์ 2569) ให้ผู้ใช้เลือก — โปรแกรมไม่เลือกวัสดุ/วิธีก่อสร้างแทน

    venv/bin/python -m yotathai.boq.map_ifc MODEL.ifc OUT.csv [--json OUT.json]

- กติกาอยู่ที่ `rules.json` (ไม่ฝังตัวเลขในโค้ด) · ทดสอบ `yotathai/tests/test_boq_ifc.py`
- **1 วัตถุที่ติดแท็ก = 1 ชิ้นงานจริง** (ผนัง 1 แนว/พื้น 1 แผ่น): ตัวส่งออก IFC ของ src/core/bim.py วัดผนังและพื้นจาก
  "หน้าที่ใหญ่สุดหน้าเดียว" ถ้ารวมผนังหลายแนวเป็นกลุ่มเดียว ปริมาณจะต่ำกว่าจริง
- ชื่อรายการใน boq-catalog.json มีอักขระฟอนต์ PDF (U+F70A…) แทนไม้เอก/โท — `thai_text.fix_thai` แปลงเป็นอักขระจริงตอนอ่าน (ไฟล์ข้อมูลเดิมไม่ถูกแก้)
- ยังไม่คิดราคา/Factor F — ขั้นต่อไป
