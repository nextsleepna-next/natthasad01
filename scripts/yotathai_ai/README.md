# yotathai_ai — สั่งงาน Yotathai (2D + 3D) โดยไม่เปิดหน้าจอ

สำหรับ AI และสคริปต์ · รันจากโฟลเดอร์โปรเจกต์:

```bash
# Mac/Linux (จากซอร์ส)
venv/bin/python scripts/yotathai_ai <คำสั่ง> ... [--json]
# Windows (แพ็กเกจพกพา) — ที่โฟลเดอร์แพ็กเกจ
yotathai-ai.bat <คำสั่ง> ... [--json]
```

| คำสั่ง | ทำอะไร |
|---|---|
| `plan-to-3d PLAN.dxf MODEL.igz` | ยกแปลน 2D เป็นโมเดล 3D (ผนังเส้นคู่/เส้นกึ่งกลาง, ประตู, หน้าต่าง, เสา, พื้น, ห้อง+พื้นที่) · ตัวเลือก `--height --door-height --sill --head --thickness --wall-layers --door-layers --window-layers --column-layers --handles ไฟล์ --glb --ifc` |
| `model-to-2d MODEL.igz SHEET.dxf` | ผังพื้นตัดตามระดับ + ผังหลังคา + รูปด้าน 4 ด้าน ในไฟล์เดียว หน่วยเมตร · `--cuts 1.65,5.65 --no-roof --no-elevations --workers N --layout A3` · ไฟล์ไม่มีพื้นหลังใดๆ (เส้น+แฮตช์เทา+ตัวอักษรเท่านั้น) · `--layout A3` (A4–A0) เพิ่ม Layout กระดาษพร้อมช่องมองมาตราส่วนกลมๆ (เช่น 1:200) พิมพ์พื้นขาวได้เลย |
| `room-import / room-add / room-list / room-check / room-suggest / room-remove MODEL.igz ...` | ป้ายห้อง (ชื่อ ชนิด ชั้น ขอบเขต) เก็บในไฟล์โมเดล · `model-to-2d --room-fill off\|presentation\|construction` ลงสีพื้นห้องใต้เส้นผนัง (ค่าตั้งต้น off) · `room-suggest` เสนอจากผนังเท่านั้น ต้องยืนยันก่อนใช้ · วิธีใช้เต็ม `docs/room-labels-usage-691101.md` |
| `build-3d RECIPE.py MODEL.igz` | รันสูตร 3D: ในสคริปต์มี `house() wall() extrude() prism() revolve() scene tag()` · `--glb --ifc` (IFC ต้อง `tag(group, "IfcWall", "ชื่อ")` ก่อน) · ดูสูตรทั้งหมด: `recipes` |
| `draw-2d SCRIPT.py DRAWING.dxf` | รันสคริปต์ ezdxf: มี `doc msp ezdxf` ตั้งหน่วยเมตร R2018 · สไตล์ตัวอักษรไทย `TH` (Tahoma) · `TH-DRAFT` (Yotathai Drafting) · `TH-KANIT` · `TH-SARABUN` (ฟอนต์แจกต่อได้ที่มากับแพ็กเกจ — อ้างชื่อ ไม่คัดลอกไฟล์) |
| `to-dwg IN.dxf OUT.dwg` | บันทึก DWG ผ่าน LibreDWG (ได้ AutoCAD R2000 รุ่นเดียว · ข้อความไทยถูกเข้ารหัส \U+xxxx ซึ่ง AutoCAD อ่านได้) |
| `calc-beam JOB.json` | คำนวณคาน คสล. วิธีกำลัง (SDM) ดัด+เฉือน ตาม วสท. 011008-21 + กฎกระทรวง 2566 จากไฟล์งาน JSON สั้นๆ (ตัวอย่าง `ytstruct/examples/beam-job.json` · รูปแบบเต็มที่หัวไฟล์ `ytstruct/cli.py`) · ได้ไฟล์ผล `<JOB>.result.json` + สรุปภาษาไทย (ผ่าน/ไม่ผ่าน เหตุผล เลขข้อ สมมติฐาน สิ่งที่ยังไม่ได้ตรวจ) · `--out ไฟล์ --steps` (ขั้นคำนวณทุกขั้นพร้อมเลขข้อ) · ต้องมีชุดคำนวณ `ytstruct` (ความรู้ในบ้าน ไม่แจกพร้อมโปรแกรม) · f′c เกรดเหล็ก qc_noted ระยะหุ้ม/d และแรง ไม่มีค่าเริ่มต้น ต้องใส่เอง |
| `calc-rc list [--filter คำ]` · `calc-rc ฟังก์ชัน JOB.json [--out X]` | เรียก**ทุกฟังก์ชัน**ของเอนจินออกแบบห้อง RC-Design (แรงลม แผ่นดินไหว วิเคราะห์โครง คาน เสา พื้น บันได ฐานราก เหล็กรูปพรรณ ฯลฯ ~200 ฟังก์ชัน) จากสำเนาเอนจินในชุด `ytstruct/rcdesign/engine` (commit ใน `ENGINE-COMMIT.txt` · ปรับเป็นฉบับล่าสุดด้วย `python -m ytstruct rc sync`) · ฟังก์ชันนอก index ระบุ `โมดูล:ฟังก์ชัน` · JOB เป็นอ็อบเจ็กต์หรืออาร์เรย์ของอาร์กิวเมนต์ · ผลบันทึก commit ที่ใช้ · ต้องมี Node (TypeScript มากับชุดแล้ว) · ใส่ `--ref กิ่ง` เพื่อเรียกฉบับอื่นจากคลังของเขาโดยตรง |
| `job-new ชื่อสั้น --province จังหวัด --amphoe อำเภอ [--name-th ชื่อ] [--dest โฟลเดอร์]` | สร้างโครงการใหม่จากแม่แบบแฟ้มงาน Yotathai-AI-BIM (หาเองที่ `~/Yotathai_Pro/Yotathai-AI-BIM` หรือ `YOTATHAI_KIT`) · เติมค่าลม V50/TF/กลุ่ม และ Ss/S1/บริเวณแผ่นดินไหว ตามจังหวัด/อำเภอให้เองพร้อมที่มา (ถ้าข้อมูลไม่พอ บอกว่าขาดอะไร ไม่เดา) · ใส่ฟอนต์เอกสารให้ |
| `job-run โฟลเดอร์โครงการ [--from N] [--only calc,price] [--list] [--render]` | รันทั้งสายในคำสั่งเดียว: โมเดล 3D → คำนวณโครงสร้าง → แบบ A/S/MEP → ตรวจมาตรฐานแบบ → เล่มขออนุญาต → เล่มนำเสนอ → ถอดแบบ BOQ + ราคากลาง ปร.1–ปร.4 (PDF+xlsx) → ระยะเวลาก่อสร้าง งวดงาน-งวดเงิน S-curve · ผล JSON บอกไฟล์ทั้งหมด (บ้านตัวอย่าง ~1.5 นาที) |
| `calc-building SPEC.json --out โฟลเดอร์งาน [--steps 10]` | อาคารกริด 1–10+ ชั้น: เกณฑ์ตามที่ตั้ง (แผ่นดินไหว ลม นจ.) → โครง 3 มิติ (แผ่นดินไหว ELF + แรงลม มยผ.1311-50) → ออกแบบคาน/เสา/ข้อต่อ SDM → ขยายเฉพาะส่วนที่ไม่ผ่านจนผ่าน → ฐานรากทุกกรณีดิน · สเปกดู `ytstruct/building_spec.py` |
| `job-building โฟลเดอร์โครงการ [--spec สเปก.json] [--skip-sheets]` | ทั้งสายอาคารกริดในโครงการที่สร้างด้วย `job-new` (สเปกที่ `calc/building-spec.json`): คำนวณโครง SDM → ฐานราก → พื้น/บันได → แบบโครงสร้าง S → ถอดแบบงานโครงสร้าง + ราคากลาง ปร.1–ปร.4 (PDF/xlsx ราคา สนค./ว480/ว481) → ระยะเวลา (เกณฑ์อาคารของ construction-time-app) งวดงาน S-curve · ราคาเป็นงานโครงสร้างเท่านั้น |
| `calc-foundation โฟลเดอร์งาน [--soil ค่าดิน.json]` | ฐานแผ่/ฐานหัวเข็ม/ฐานร่วมจากแรงที่ฐานเสาของงานที่ออกแบบโครงแล้ว · ค่าดินเริ่มต้นตามกฎกระทรวงฐานราก 2566 ข้อ 7–8 (`ytstruct/frame/defaults/soil.json`) แทนด้วยผลเจาะดินของโครงการ → check/foundation_*.csv · run/final/foundations.json |
| `job-k โฟลเดอร์โครงการ --signed 2569-01-15 --bid-open 2568-12-10 [--approval วันที่] [--formula 1] [--indices ไฟล์]` | ค่า K รายงวดจากแผนงวดงานของโครงการ (สูตร 1 งานอาคาร ค่าเริ่มต้น) · ทศนิยม 3 ตำแหน่งตัดสองจังหวะ ตาม ว 109 · เกณฑ์ ±4% / ±2% (ว 190) อัตโนมัติ · ดัชนีจากไฟล์ที่กรอก หรือ snapshot ในชุด (เดือนที่ไม่มีดัชนี = แจ้งรายการ ไม่เดา) → out/k/k-result.md |
| `price-road JOB.json [--xlsx ไฟล์] [--out ผล.json]` | ราคากลางงานทาง สะพาน ท่อเหลี่ยม ชลประทาน (หลักเกณฑ์ 2569: ว475 ว477 ว480 ว481 Factor F) จากเครื่องคำนวณ rakaklang-sim (357 สูตร) · รูปแบบ JOB ดู `ytstruct/roadbridge/README.md` + ตัวอย่างใน examples/ |
| `time-road JOB.json` | ระยะเวลาก่อสร้าง + จำนวนงวดงานทาง/สะพาน (คู่มือบริหารงานทาง อปท. 2566) จาก construction-time-app |
| `road-section --surface S --cbr N (--adt N \| --trucks10 N) [--variant type1\|type2] [--base crushed_rock\|soil_cement] [--life 7\|10] [--width M]` | เลือกหน้าตัดชั้นทางตามแบบมาตรฐานท้องถิ่น อปท. (ทถ-) ฉบับหลัก 2556: แผ่น · หน้า PDF · ความหนาแต่ละชั้น · ธง (ค่าที่แผ่นเว้นว่าง/ต่ำกว่าแถวที่พิมพ์ = ปฏิเสธพร้อมเหตุผล ไม่เดา) · ผิวทาง `concrete_reinforced concrete_plain cape_seal dbst asphalt_concrete gravel gravel_stabilized soil_cement_surface` · **แพ็กทักษะแยก** (`ytstruct/infra` + สกิล `yotathai-road-sheets-2556`) ไม่รวมในโปรแกรมฟรี ไม่ได้ติดตั้งจะบอกชัดเจน |
| `road-takeoff` (พารามิเตอร์เดียวกัน + `--width M [--length M]`) | ปริมาณชั้นทางต่อ กม./สายทาง พร้อมสูตรและรายการที่ "ไม่รวม" |
| `road-sheets` (เหมือน `road-takeoff` + `[--out-dir DIR] [--pdf] [--project ชื่อ] [--site ที่ตั้ง] [--code RD-01] [--paper A3]`) | แผ่นรูปตัดโครงสร้างชั้นทาง 2D (DXF [+PDF/PNG]) · ใช้ภายในทีม ต้องให้วิศวกรตรวจเทียบแผ่นจริง · ไม่ใช่ชุดแบบก่อสร้างถนนครบชุด |

| `find-work [--days N] [--all] [โฟลเดอร์ ...]` | หาไฟล์งานของผู้ใช้ (.igz .dxf .dwg .skp) ใหม่สุดก่อน ในเอกสาร/เดสก์ท็อป/ดาวน์โหลด/OneDrive/ที่เก็บกู้อัตโนมัติ · ใช้เมื่อผู้ใช้อัปเดตรุ่นแล้วจำที่เก็บงานเดิมไม่ได้ |
| `recipes` | คู่มือฟังก์ชันสร้างโมเดล 3D ของเครื่องยนต์ |
| `check` | ตรวจว่าเครื่องยนต์ 2D/3D และตัวแปลงพร้อม |

ผลลัพธ์: บรรทัดสุดท้ายเป็น JSON (`{"ok": true, ...}` หรือ `{"ok": false, "error": ...}`) เมื่อใส่ `--json`

ข้อควรรู้
- แบบหลายแปลนในไฟล์เดียว (ชุดขออนุญาต): ใช้ `--handles` (รายการ handle ของเอนทิตีในแปลนที่ต้องการ บรรทัดละตัว) ไม่เช่นนั้นทุกแปลนถูกยกพร้อมกัน
- เลเยอร์ตรวจจากชื่อ: ผนัง `WALL/ผนัง/กำแพง`, ประตู `DOOR/ประตู`, หน้าต่าง `WIN/GLAZ/หน้าต่าง`, เสา `COL/COLS/COLUMN/เสา` (เสาเป็น HATCH ทึบก็ได้) · เลเยอร์ที่มีคำ `HATCH FILL DIM TEXT ANNO NOTE` ไม่นับ
- หน่วยจาก `$INSUNITS` ถ้าไม่มีเดาจากขนาด (เกิน 1,500 = มม.)
- โมเดลใหญ่: `model-to-2d` ใช้หลายแกน CPU (อาคารเทศบาล 3 ชั้น ~25 วิ)
- ตัวแปลงอยู่ที่ `yotathai/convert/` ใช้ร่วมกับเมนู «2D ⇄ 3D» ในแอป
