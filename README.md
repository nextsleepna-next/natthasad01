# Yotathai Plan — ฉบับ Claude บนเว็บ

โปรแกรม Yotathai Plan (2D/3D) แบบไม่มีหน้าจอ สำหรับผู้ที่ใช้ Claude Code บนเว็บเบราว์เซอร์ (claude.ai/code) แทนการติดตั้งบน Windows — Claude สั่งงานโปรแกรมให้ ท่านได้ไฟล์โมเดล 3 มิติ แบบ DXF/PDF และเอกสารกลับมา

## เริ่มใช้ (ประมาณ 10 นาที)
1. มีบัญชี GitHub และบัญชี Claude แบบเสียเงิน (ที่ใช้ Claude Code ได้) · **repo ต้นแบบนี้เป็นส่วนตัว** ส่งชื่อผู้ใช้ GitHub (username) ให้ผู้สอนทาง LINE @yotathaiplan เพื่อรับคำเชิญ แล้วกดยอมรับคำเชิญในอีเมล/หน้า GitHub ก่อน จึงจะเห็นปุ่ม Use this template
2. กดปุ่ม **Use this template ▸ Create a new repository** ตั้งชื่อเอง เลือก **Private** (สำคัญ)
3. ใส่แฟ้ม `AI-yotathai` ของท่านตามคู่มือใน `AI-yotathai/ใส่แฟ้มที่นี่.md`
4. เปิด claude.ai/code ▸ เชื่อม GitHub (อนุญาต Claude เข้าถึงเฉพาะ repo นี้) ▸ เลือก repo ของท่าน ▸ เริ่มเซสชันใหม่
   - ครั้งแรกเครื่องจะเตรียมตัวเองอัตโนมัติ 3–10 นาที (ติดตั้งไลบรารี) รอจนเห็นข้อความ "เสร็จ"
5. พิมพ์: **อ่านแฟ้ม AI-yotathai ก่อนเริ่มงาน** แล้วทำตามใบงานในแฟ้ม `AI-yotathai/lessons/` (ใช้คำสั่งเดียวกับที่สอน Claude จะแปลงคำสั่ง Windows ให้เองตาม `CLAUDE.md`)

## ข้อควรรู้
- ทุกครั้งที่เปิดเซสชันใหม่ ต้องพิมพ์ประโยคในข้อ 5 ซ้ำ (เหมือนในห้องอบรม)
- ไม่มีหน้าจอโปรแกรม: ดูโมเดล 3 มิติผ่านหน้าดู HTML ที่ Claude สร้างให้ · ภาพสำหรับ ChatGPT/Gemini ให้แคปจากหน้าดูนั้น
- งานเก็บในโฟลเดอร์ `work/` ของ repo ท่านเอง
- มีปัญหา แจ้ง LINE @yotathaiplan
